# Marketplace ULEAM

Marketplace académico desarrollado para estudiantes y profesores de la
Universidad Laica Eloy Alfaro de Manabí. La plataforma permite comprar,
vender e intercambiar materiales académicos dentro de la comunidad
universitaria, además de incorporar un sistema de misiones y reputación
para incentivar la participación.

------------------------------------------------------------------------

## Descripción

Este proyecto consiste en el desarrollo de una API REST que permite
gestionar un marketplace universitario donde los usuarios pueden:

-   Publicar productos académicos
-   Comprar o intercambiar recursos
-   Comunicarse entre estudiantes y profesores
-   Ganar reputación al completar misiones
-   Subir de nivel dentro de la plataforma

El objetivo es facilitar el acceso a materiales educativos y fomentar la
colaboración entre los miembros de la comunidad universitaria.
